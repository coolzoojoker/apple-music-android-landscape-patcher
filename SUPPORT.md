# 自愿支持 / Voluntary Support

本项目免费提供补丁源码和本地构建工具。赞赏完全自愿，不解锁功能、不提供修改版 APK，也不构成 Apple Music 服务或内容的销售。

This project provides its patch source code and local build tools free of charge. Support is entirely optional, unlocks no features, and does not provide a modified Apple Music APK or sell any Apple Music service or content.
