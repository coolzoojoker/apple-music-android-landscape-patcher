# Windows 快速操作指南

全程可通过中文向导完成，无需命令行操作。补丁器只在你的电脑本地工作，不会上传 Apple Music 安装包、账号或签名密钥。

## 你需要准备什么

- Windows 10 或 Windows 11 的 64 位电脑。
- 至少 5 GB 可用空间和稳定网络。
- Android 11 或更高版本的电视 / 平板 / 车机，并且设备允许安装第三方 APK。
- 电视端使用 USB / 蓝牙鼠标、空中鼠标，或能够模拟屏幕指针的遥控器；普通方向键遥控器尚未完整适配。
- 你自己的 Apple Music 账号和订阅（补丁不会提供或绕过服务资格）。
- 指定的 Apple Music 6.5.0 (1580) APKM。

## 第一步：下载补丁器

1. 打开本项目的 **Releases**。
2. 下载名称类似 `AppleMusic-Landscape-Patcher-Windows-*.zip` 的文件。
3. 右键 ZIP，选择“全部解压”。不要直接在压缩包预览窗口里运行。
4. 打开解压后的文件夹，确认能看到 `Start-Patcher.cmd`。

补丁器 ZIP 不含 Apple Music 安装包、Apple 图片资源、通用签名密钥或预先修改好的 APK。

Release 页面显示的 SHA-256 是 ZIP 的可选校验指纹，不是密码或激活码。正常使用时无需复制、输入或提供给作者。需要自行校验时，可在补丁器 ZIP 所在目录打开 PowerShell，运行：

```powershell
Get-FileHash ".\AppleMusic-Landscape-Patcher-Windows-*.zip" -Algorithm SHA256
```

## 第二步：自行取得基础包

支持的基础包如下：

- 来源页面：[APKMirror — Apple Music 6.5.0 (1580)](https://www.apkmirror.com/apk/apple/apple-music/apple-music-6-5-0-release/apple-music-6-5-0-android-apk-download/)
- 文件类型：APK Bundle / APKM，不是单独的 base APK。
- 页面标注大小：160.99 MB（168,814,164 字节）。
- 期望文件名：`com.apple.android.music_6.5.0-1580_4arch_7dpi_e7097cc310a6e34d1c0e3dc70145ee78_apkmirror.com.apkm`
- 自动校验值：`18F1B7A0296FBF059D68509506729D6A291408BE43E3CE50060E15E5E8B2941A`

APKMirror 是第三方网站，与本项目无隶属关系。你也可以从其他合法来源取得完全相同的文件；向导会自动校验内容，不要求文件位于特定目录。请自行确认所在地法律、Apple 条款和来源条款。

## 第三步：双击构建

1. 双击 `Start-Patcher.cmd`。
2. 输入 `Y` 同意继续。
3. 在弹出的窗口选择第二步下载的 `.apkm` 文件。
4. 按屏幕说明选择一种设备配置：

   - `1`：索尼 K-85XR70 或已经验证的类似 32 位 xhdpi 电视。
   - `2`：普通 64 位 Android TV / Google TV / Android 平板。
   - `3`：普通 32 位 Android TV / Android 平板。
   - `4`：多数较新的 64 位 Android 车机。
   - `5`：较老的 32 位 Android 车机。

5. 保持窗口开启。第一次会自动下载并校验 APKEditor、Apktool、Temurin JDK、Android SDK 和可选安装工具 ADB。
6. 显示“构建完成”后，资源管理器会自动选中生成的 APK。

横屏 Android 平板选择与 CPU 架构相符的 TV 配置即可；平板适配目前尚未按具体型号完成验证。

如果 Windows 阻止脚本运行，请确认 ZIP 来自本项目 Release，并在 ZIP 的“属性”里勾选“解除锁定”后重新解压。不要关闭杀毒软件，也不要使用管理员权限运行；正常构建不需要管理员权限。

## 第四步：安装到电视

### 方法一：U 盘或电视存储安装（不需要 ADB）

1. 把 `dist` 文件夹里的 TV 版 APK 复制到 U 盘、电视内部存储或电视能访问的局域网共享目录。
2. 在电视设置中允许所用文件管理器“安装未知应用”。
3. 使用电视文件管理器打开 APK，按电视提示安装。

不同品牌对未知来源应用的限制不同。如果电视没有文件管理器、无法访问 APK，或安装失败但不显示具体原因，可以改用网络 ADB。

### 方法二：网络 ADB 安装（可选）

1. 在电视设置里开启“开发者选项”和“网络调试 / ADB 调试”。不同品牌名称可能不同。
2. 让电脑和电视连接同一个局域网，记下电视 IP。
3. 构建完成后，向导询问是否安装时输入 `Y`。
4. 输入电视 IP；如电视明确显示了端口，输入 `IP:端口`，否则向导默认使用 `5555`。
5. 第一次连接时，在电视上选择允许这台电脑调试。
6. 向导会显示电视型号、Android 版本和 CPU 架构，再尝试覆盖安装。

补丁使用你电脑本地生成的签名，通常不能覆盖 Apple 官方签名的原版。如果看到 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，先确认账号和离线下载可以恢复，再由你手动卸载原版并重新运行安装。向导不会自动卸载应用、清除数据或改动电视系统。

两种安装方式得到的应用相同。ADB 只负责把已经生成的 APK 发送到电视并执行安装，不参与播放器功能。

## 第五步：安装到车机

1. 把 `dist` 文件夹里的 APK 复制到 U 盘，或复制到车机允许访问的目录。
2. 使用车机厂商允许的文件管理器 / 应用安装入口安装。
3. 如果车机禁止第三方安装、要求系统签名或工程密码，请停止；本项目不提供绕过方法。
4. 驾驶时不要安装、调试或操作播放器。

## 签名密钥备份

第一次构建会在 `.local\signing` 生成只属于你的签名密钥。请完整备份这个文件夹。同一密钥签名的版本可以相互覆盖；丢失密钥后通常只能卸载再装。

不要把 `.local\signing`、生成的 APK、ADB 地址、设备序列号或包含账号信息的日志上传到 Issue。

## 常见错误

- **基础包校验失败**：下载的版本、变体或文件内容不对。回到第二步核对，不需要手动修改校验值。
- **电视文件管理器无法安装**：确认已允许该文件管理器安装未知应用；仍失败时使用网络 ADB 查看具体错误。
- **工具下载失败**：检查网络后重新运行；已经校验完成的文件会复用。
- **电视未授权**：查看电视屏幕上的 ADB 授权弹窗。
- **签名不兼容**：官方版与本地补丁版签名不同；向导不会自动卸载原版。
- **车机解析包失败**：先核对 Android 版本、CPU 架构和厂商是否允许安装第三方 APK。
